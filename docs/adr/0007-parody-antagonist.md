# 0007 — The antagonist is a parody, not a real person, and the theme borrows no franchise IP

**Status:** accepted · 2026-10-13

## Context
The intended story is "defeat Mark Zuckerberg's army", in a game inspired by Tower of God. For a public game, naming or depicting a real person as a villain risks right-of-publicity and defamation claims and platform takedowns. Using a franchise's names, characters or terms risks copyright and trademark claims.

## Decision
The army is the **Meta Legion**, led by **Zark** (working name): a recognisable parody that uses no real name, likeness or logo. The theme uses only generic genre ideas (tower, floors, tests, ranks, team roles, perks) and none of the source's names or terminology.

## Consequences
- Same joke, much lower legal exposure.
- If the owner later decides to use a real name, record that in a new ADR that supersedes this one.
